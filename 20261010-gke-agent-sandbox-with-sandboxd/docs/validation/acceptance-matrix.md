# GKE acceptance scenario coverage

This table maps the 16 scenarios in [README section 12](../../README.md#12-テストとgkeでの受け入れ条件) to the tests and recorded evidence. A passing unit test verifies local behavior; it does not count as a real-cluster result. Scenario 9.2 stays open until the missing GKE cases below are added to and run from the in-cluster suite.

| # | README scenario | Unit coverage | GKE evidence | Remaining GKE coverage |
| ---: | --- | --- | --- | --- |
| 1 | Concurrent ensure, session isolation | `test_manager.py` | `session-manager-gke.md`: concurrent ensure made one Sandbox; cluster pytest run `b39a0715d2b0` verified that two simultaneous sessions cannot see each other's files | Add concurrent same-key ensure to the cluster pytest case |
| 2 | File REST and command gRPC, streams, stdin, exit, cancel, signal | `test_files.py`, `test_commands.py`, `test_tracker_runtime.py` | `sandboxd-runtime.md`, `session-manager-gke.md`: REST/gRPC, stdout/stderr, stdin EOF, nonzero exit, cancellation, signal; cluster pytest run `b39a0715d2b0` wrote through files and read through a tracked command | Run the complete command matrix through the cluster pytest suite |
| 3 | Suspend/resume preserves workspace and PVC | `test_manager.py`, `test_volumes.py` | `sandbox-lifecycle.md`: PVC UID and data survive Pod replacement; manager GKE run checked suspend/resume | Verify manager-owned file contents and PVC UID across suspend/resume in one test |
| 4 | Idle timeout and running command protection | `test_reconciler.py`, `test_manager.py` | `session-manager-gke.md`: real 300-second idle boundary and active one-turn protection | Add real GKE long-running silent command, parallel command, and caller-disconnect cases |
| 5 | Short retention expiry and PVC cleanup | `test_reconciler.py`, `test_manager.py` | `session-manager-gke.md`: 10-, 15- and 60-second retention probes; run `b39a0715d2b0` confirmed controller expiry with reconciler stopped | Seven-day wall-clock run is intentionally excluded; retain clock-injected boundary tests |
| 6 | New generation and durable context event ack | `test_manager.py`, `test_repository.py`, `test_sqlite_repository.py` | `session-manager-gke.md`: generation 2, empty workspace, reconnect, event ack exactly once; run `b39a0715d2b0` confirmed after controller expiry | Exercise Bot append/ack crash in an end-to-end GKE test |
