# agent-query-verification Specification

## Purpose

BYOC エージェントの各クエリ操作と長時間実行クエリジョブをローカルおよび Google Cloud 上で再現可能に実行し、応答とコンテナ到達状況を証跡に基づいて判定する。

## Requirements

### Requirement: ローカルでの4操作検証
検証手段はローカルで稼働するランタイムに対して `query`、`stream_query`、`async_query`、`async_stream_query` を個別に実行できなければならない（SHALL）。各実行では操作名、受信データ、受信順序、処理開始からの経過時間を確認できなければならない（SHALL）。

#### Scenario: 非ストリーミング操作のローカル検証
- **WHEN** 検証者がローカルランタイムに対して `query` または `async_query` を実行する
- **THEN** 検証結果は単一の `OK` とその受信時刻を示す

#### Scenario: ストリーミング操作のローカル検証
- **WHEN** 検証者がローカルランタイムに対して `stream_query` または `async_stream_query` を実行する
- **THEN** 検証結果は `Streaming OK`、`OK` の受信順序と各受信時刻を示す

### Requirement: デプロイ済みエージェントの4操作検証
検証手段は認証済みの Agent Platform SDK または REST API を使用し、デプロイ済みエージェントに対して4種類の操作を個別に実行できなければならない（SHALL）。結果には対象リソース、操作名、応答、経過時間、成否が含まれなければならない（MUST）。

#### Scenario: デプロイ済み操作の成功
- **WHEN** 検証者が有効な認証情報とエージェントリソース名で操作を実行する
- **THEN** 検証結果は期待する応答内容、順序、経過時間とコンテナ側の対応ログを照合できる形で示す

#### Scenario: デプロイ済み操作の失敗
- **WHEN** Agent Platform API またはデプロイ済みコンテナが操作を完了できない
- **THEN** 検証結果は操作名、API エラーまたはタイムアウト、および対応するコンテナログの有無を示す

### Requirement: 再現可能なデプロイ手順
検証者は値をリポジトリへ保存せずに Google Cloud のプロジェクト、リージョン、イメージ、およびサービスアカウントを設定し、コンテナのビルド、push、デプロイ、状態確認、削除を再現できなければならない（SHALL）。

#### Scenario: デプロイ準備
- **WHEN** 検証者が必要な設定値と Google Cloud 認証を用意する
- **THEN** 文書化された手順からコンテナイメージとデプロイ済みエージェントを作成できる

#### Scenario: 検証後の後片付け
- **WHEN** 検証者が削除手順を実行する
- **THEN** 検証用に作成したエージェントリソースを特定して削除できる

### Requirement: 長時間実行クエリジョブの疎通判定
検証手段はデプロイ済みエージェントに対して長時間実行クエリジョブを開始し、ジョブ名を保存し、終了状態まで監視できなければならない（SHALL）。検証は、ジョブ開始 API の成否、状態遷移、出力先の結果、対象時間帯のコンテナログを収集し、コンテナへの到達を「到達確認」「未到達」「判定不能」のいずれかとして報告しなければならない（MUST）。未到達も有効な検証結果として扱わなければならない（MUST）。

#### Scenario: 長時間ジョブがコンテナへ到達する
- **WHEN** ジョブ開始後に同じ検証入力に対応するコンテナの受信ログが見つかる
- **THEN** 検証結果はジョブ状態、出力、および受信から終了までの対応ログとともに「到達確認」と報告する

#### Scenario: ジョブは開始するがコンテナ到達を確認できない
- **WHEN** ジョブ開始 API はジョブ名を返すが、監視期限内に対応するコンテナ受信ログが見つからない
- **THEN** 検証結果は確認した時間範囲、ジョブ状態、出力の有無、検索条件とともに「未到達」と報告する

#### Scenario: 証跡不足で判定できない
- **WHEN** 権限不足、ログ欠落、監視期限超過などにより到達の有無を確定できない
- **THEN** 検証結果は不足した証跡と原因を添えて「判定不能」と報告する
