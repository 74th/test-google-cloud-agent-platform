## ADDED Requirements

### Requirement: 長時間実行クエリ用ルートエンドポイント
ランタイムは、既存の単項エンドポイントを維持したまま `POST /` でも Agent Platform の単項ランタイム要求を受け付けなければならない（MUST）。ルートエンドポイントは、同じ入力に対して既存の単項エンドポイントと同じ処理結果および安全なライフサイクルログを生成しなければならない（SHALL）。

#### Scenario: ルートパスで単項要求を処理する
- **WHEN** `POST /` が有効な単項ランタイム要求を受信する
- **THEN** ランタイムは指定された単項操作を実行し、`POST /api/reasoning_engine` と同じ形式の最終応答を返す

#### Scenario: ルートパスへの配送を追跡する
- **WHEN** Agent Platform から `POST /` へ HTTP リクエストが配送される
- **THEN** ランタイムは入力本文や認証情報を記録せず、ルートパスへの受信、処理開始、処理終了または安全なエラーを同一リクエストとして追跡できるログを出力する

#### Scenario: 既存単項エンドポイントとの互換性を維持する
- **WHEN** 有効な単項ランタイム要求を `POST /api/reasoning_engine` へ送信する
- **THEN** ランタイムはルートエンドポイント追加前と同じ形式および内容の応答を返す
