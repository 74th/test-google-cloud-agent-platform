## MODIFIED Requirements

### Requirement: 再現可能なデプロイ手順
検証者は値をリポジトリへ保存せずに Google Cloud のプロジェクト、リージョン、イメージ、およびサービスアカウントを設定し、コンテナのビルド、push、デプロイ、状態確認、削除を再現できなければならない（SHALL）。長時間実行クエリを行う構成は、実行サービスアカウントが指定された GCS 入出力オブジェクトを読み書きし、対象プロジェクトで必要な Google Cloud API を利用できる権限を宣言的に付与しなければならない（MUST）。

#### Scenario: デプロイ準備
- **WHEN** 検証者が必要な設定値と Google Cloud 認証を用意する
- **THEN** 文書化された手順から必要な IAM を含むコンテナイメージとデプロイ済みエージェントを作成できる

#### Scenario: 長時間ジョブの GCS 入力取得
- **WHEN** 長時間ジョブの proxy が実行サービスアカウントとして指定された入力オブジェクトを取得する
- **THEN** GCS オブジェクト権限と Service Usage 権限の両方を満たし、権限拒否なしで入力を取得できる

#### Scenario: デプロイ前の権限不足
- **WHEN** 実行サービスアカウントに長時間ジョブの前提権限が不足している
- **THEN** 検証手順は不足する権限を特定でき、コンテナ到達失敗として誤分類しない

#### Scenario: 検証後の後片付け
- **WHEN** 検証者が削除手順を実行する
- **THEN** 検証用に作成したエージェントリソースと追加した IAM を特定して削除できる

### Requirement: 長時間実行クエリジョブの疎通判定
検証手段はデプロイ済みエージェントに対して GCS 入出力を使用する長時間実行クエリジョブを開始し、ジョブ名と実際に使用された入力・出力 URI を保存し、終了状態まで監視できなければならない（SHALL）。検証は、ジョブ開始 API、状態遷移、operation の最終エラー、出力オブジェクト、proxy コンテナによる GCS 配送、job コンテナの HTTP および処理ログを収集し、失敗地点または成功を段階別に報告しなければならない（MUST）。権限不足または proxy 失敗を、HTTP 配送済みまたは単なるコンテナ未到達として扱ってはならない（MUST NOT）。

#### Scenario: GCS 入力取得前に失敗する
- **WHEN** proxy コンテナが権限不足などにより入力 GCS オブジェクトを取得できない
- **THEN** 検証結果は GCS 入力取得失敗、対象コンテナ、最終 operation エラーを示し、`POST /` は未実行として報告する

#### Scenario: 長時間ジョブがコンテナへ到達する
- **WHEN** proxy が GCS 入力を取得し、同じ検証入力に対応する `POST /` の受信ログが見つかる
- **THEN** 検証結果は実入力 URI、HTTP ステータス、ジョブ状態、出力、および受信から終了までの対応ログを示す

#### Scenario: ジョブは開始するがコンテナ到達を確認できない
- **WHEN** ジョブ開始 API はジョブ名を返すが、監視期限内に GCS 入力取得または対応するコンテナ受信を確認できない
- **THEN** 検証結果は確認した時間範囲、実入力・出力 URI、ジョブ状態、proxy と job のログ、operation エラー、検索条件を示し、確認できた最終段階を報告する

#### Scenario: アプリケーション処理が失敗する
- **WHEN** `POST /` は実行されたが入力検証またはクエリ処理が成功しない
- **THEN** 検証結果は HTTP 配送成功とアプリケーション処理失敗を区別し、HTTP ステータスと安全なエラー分類を示す

#### Scenario: 短時間ジョブの経路確認
- **WHEN** 検証者が既定の約10秒の入力で長時間ジョブ経路を実行する
- **THEN** ジョブは成功終端し、`POST /` の成功、期待する GCS 出力、対応ログを一つの試行として確認できる

#### Scenario: 15分を超えるジョブの完了確認
- **WHEN** 短時間ジョブの経路確認後に15分を超える処理時間を指定してジョブを実行する
- **THEN** 検証手段は処理時間より長い監視期限でキャンセルせず監視し、成功終端、経過時間、GCS 出力、対応ログを報告する

#### Scenario: 証跡不足で判定できない
- **WHEN** ログ欠落、監視期限超過、または API の詳細不足により失敗地点を確定できない
- **THEN** 検証結果は取得できた段階、欠けた証跡、実際の検索条件を添えて「判定不能」と報告する
