# Spec Delta

## Purpose

ローカルのオペレータが 1 つのコマンドでプロンプトを Agent Sandbox 上のエージェントに送り、応答を受け取れるようにする。セッション ID を指定すれば、会話とワークスペースを引き継いで続きの対話ができる。

## ADDED Requirements

### Requirement: 新しいセッションでプロンプトを実行する
CLI は、セッション ID を指定せずにプロンプトを受け取った場合、新しいセッション ID を発行しなければならない（SHALL）。そのうえで、セッション用の入力 JSONL を GCS に保存し、永続ワークスペースを持つ Sandbox を作成して Agent Runner を実行しなければならない（SHALL）。

#### Scenario: 初回実行
- **WHEN** オペレータがセッション ID なしでプロンプトを指定して CLI を実行する
- **THEN** CLI は Sandbox の終了を待ってから、応答本文とセッション ID を標準出力に表示し、終了コード 0 で終了する

### Requirement: Sandbox が終了するまで監視する
CLI は、Sandbox 内の Agent Runner が終了するまで状態を監視し、進捗（作成、スケジュール、実行中、終了）を表示しなければならない（SHALL）。タイムアウトは設定できなければならず（SHALL）、タイムアウトまたは異常終了した場合は、原因の手がかり（Pod のイベントやコンテナログの末尾）を表示して非ゼロで終了しなければならない（SHALL）。

#### Scenario: Agent Runner が異常終了する
- **WHEN** Agent Runner が非ゼロで終了する
- **THEN** CLI はコンテナログの末尾を表示し、非ゼロで終了する

#### Scenario: タイムアウト
- **WHEN** 指定したタイムアウトまでに Agent Runner が終了しない
- **THEN** CLI はタイムアウトしたことと Pod の状態を表示し、非ゼロで終了する

### Requirement: セッション ID で続きの対話を行う
CLI は、既存のセッション ID とプロンプトを受け取った場合、そのセッションの JSONL に新しい行を追加しなければならない（SHALL）。そして、同じ Sandbox と同じ永続ワークスペースで Agent Runner を再実行し、前回の Claude セッションを再開しなければならない（SHALL）。

#### Scenario: 続きの対話
- **WHEN** オペレータが前回表示されたセッション ID とプロンプトを指定して CLI を実行する
- **THEN** 応答は前回の会話を踏まえたものになり、前回と同じセッション ID が表示される

#### Scenario: 存在しないセッション ID
- **WHEN** オペレータが存在しないセッション ID を指定する
- **THEN** CLI は Sandbox を作成せず、セッションが見つからないことを表示して非ゼロで終了する

### Requirement: 実行後はリソースを解放し、ワークスペースは保持する
CLI は、Agent Runner が終了したら Sandbox を一時停止し、計算リソースを解放しなければならない（SHALL）。このとき永続ワークスペースは保持しなければならない（SHALL）。セッションを明示的に削除するサブコマンドでは、Sandbox と永続ワークスペースを削除しなければならない（SHALL）。

#### Scenario: 実行後に Pod がなくなり、ボリュームは残る
- **WHEN** CLI の実行が完了する
- **THEN** そのセッションの Pod は存在せず、永続ボリュームの PVC は `Bound` のまま残っている

#### Scenario: セッションを削除する
- **WHEN** オペレータがセッション削除サブコマンドを実行する
- **THEN** 対象セッションの Sandbox と PVC が削除される

### Requirement: 実行の詳細を確認できる
CLI は、オプションを指定すると、応答に加えて出力行の実行メタデータ（Pod UID、ノード、カーネル情報、ワークスペースのファイル一覧、Claude セッション ID）を JSON で表示できなければならない（SHALL）。

#### Scenario: 詳細表示
- **WHEN** オペレータが詳細表示オプションを付けて CLI を実行する
- **THEN** 実行メタデータが JSON で表示される
